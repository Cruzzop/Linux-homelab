# Linux Users and Permissions

**Status: Planned**

Topics to practise:
- Users and groups
- `whoami`, `id`, and `groups`
- File ownership with `chown`
- Permissions with `chmod`
- Reading permission strings such as `-rwxr-xr--`
- The purpose of `sudo`

Do not change ownership or permissions on system files while practising. Use a test directory inside your home directory.
