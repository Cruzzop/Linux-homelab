# Linux Basic Commands

Beginner command reference. Practise each command in the Ubuntu VM and add notes about the output.

| Command | Purpose |
|---|---|
| `pwd` | Show the current directory |
| `ls -la` | List files, including hidden files, with details |
| `cd` | Change directory |
| `mkdir` | Create a directory |
| `touch` | Create an empty file or update its timestamp |
| `cp` | Copy files or directories |
| `mv` | Move or rename files |
| `rm` | Remove files (use carefully) |
| `cat` | Print file contents |
| `less` | View a file page by page |
| `whoami` | Show the current username |
| `uname -a` | Show kernel and system information |
| `man <command>` | Open a command's manual |

## Practice checklist

- [ ] Navigate between directories
- [ ] Create, copy, rename, and remove a test file
- [ ] Read a command's manual page
- [ ] Record terminal output from a practice session

> Be careful with `rm`, especially when using options such as `-r` or `-f`.
