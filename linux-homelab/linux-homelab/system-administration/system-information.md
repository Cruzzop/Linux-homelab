# System Information

Use these commands to inspect the Ubuntu VM:

```bash
hostnamectl
uname -r
free -h
df -h
uptime
lscpu
```

| Command | What it shows |
|---|---|
| `hostnamectl` | Hostname and operating system details |
| `uname -r` | Running kernel version |
| `free -h` | Memory usage |
| `df -h` | Filesystem disk usage |
| `uptime` | System uptime and load averages |
| `lscpu` | CPU architecture and processor details |

Record the date and relevant output when you run these commands.
