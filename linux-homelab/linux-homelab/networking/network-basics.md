# Networking Basics in Ubuntu

**Status: Planned**

Commands to explore:
```bash
ip addr
ip route
ping -c 4 1.1.1.1
hostname
hostname -I
ss -tuln
```

Learning goals:
- Understand IP addresses and network interfaces
- Identify the default route and gateway
- Understand basic connectivity testing
- Inspect listening TCP/UDP sockets

Only scan or test systems and networks you own or have explicit permission to assess.
