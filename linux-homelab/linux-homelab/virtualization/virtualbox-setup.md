# Ubuntu on Oracle VirtualBox

## Overview

I use Oracle VirtualBox to run Ubuntu as a virtual machine (VM). A virtual machine allows an operating system to run in an isolated environment without replacing the host operating system.

## Useful VirtualBox concepts

- **Host:** The physical computer running VirtualBox.
- **Guest:** The operating system running inside the VM.
- **Virtual disk:** A file used by the VM as its storage drive.
- **Snapshot:** A saved state that can help return a VM to an earlier point.
